How does my ocean website actually work?

Hi! I'm Abdullah Raza. I built OceanQuest with help from ChatGPT. Here's how Hugo turns my files into a website, and how GitHub Pages lets everyone visit it online.

Start exploring ↓

01 · The idea

What is a static site generator?

Imagine writing pages in a notebook, then using a clever machine to turn them into a beautifully designed book. A static site generator does something similar for websites.

YOU WRITE

📝 Markdown

Simple text files contain titles, paragraphs, and fascinating ocean facts.

HUGO BUILDS

⚙️ Templates

Hugo combines the content with layouts to create finished HTML pages.

BROWSER SHOWS

🌐 Website

The browser displays pages, pictures, colors, and interactive JavaScript activities.

Fun fact: “Static” doesn't mean boring! OceanQuest still has animations, clickable discoveries, and quizzes. JavaScript makes the finished pages interactive.

02 · My building tool

Why I used Hugo

📚 Easy to organize

Markdown keeps educational facts separate from the website's appearance.

🖼️ Great for pictures

Hugo has built-in image processing that can resize and optimize images when we use it in our templates.

⚡ Quick builds

Hugo generates pages quickly, so I can change something and see the result.

💾 Works offline

Once built with portable links and local assets, the finished site can be copied to a USB drive.

03 · The journey from code to website

Four steps to publish OceanQuest

1. Create

I edit Markdown, HTML, CSS and JavaScript.

2. Save

Git records changes and GitHub stores the project.

3. Build

GitHub Actions runs Hugo automatically.

4. Share

GitHub Pages hosts the finished website.

GitHub is where my project files live. GitHub Actions is the robot that builds the website. GitHub Pages is the place where visitors see it.

04 · Online and offline

Two ways to explore the same ocean

Online: GitHub PagesOffline: School USB drive
Visit a website addressOpen index.html from the USB drive
Needs an internet connectionNo internet required
GitHub Actions builds the published siteHugo builds a portable public/ folder
Friends can visit from anywhereGreat for a reliable school demonstration

Important: A GitHub Pages build and a USB build can need different URL settings. We test the USB version by opening it with file:// while disconnected from Wi-Fi.

05 · Try it yourself

What commands build the site?

On the development computer, Hugo starts a preview server:

hugo server

To create the finished files for the USB drive:

hugo --cleanDestinationDir

To publish online, I push my changes to GitHub. GitHub Actions runs Hugo and GitHub Pages serves the result.
