MEET THE YOUNG EXPLORER

Hi! I'm Abdullah Raza.

Grade 6 · New Middle East International School

Welcome to my project, OceanQuest — The Secret World Under the Ocean! I wanted to make learning about oceans, marine life, latitude and longitude exciting. With help from ChatGPT, I turned that idea into an interactive website.

My biggest discovery? AI can help me create and learn, but asking questions, checking answers and trying improvements matter too.

THE ADVENTURE / 7 CHAPTERS

How OceanQuest came to life.

These steps follow the actual development conversations. They show decisions and problems, not just a finished website.

01
THE CHALLENGE

Can my website work without the internet?

We started with a school competition and a USB drive. I needed a website I could show at school without Wi-Fi.

What I learned: A static website can run locally in a browser.

02
COMPARE & DECIDE

Why I chose Hugo

I asked ChatGPT how to create an image-rich website that works online and from a USB drive. We chose Hugo because it builds static pages, organizes Markdown content and offers built-in image processing.

What I learned: AI suggestions are a starting point. Comparing options helps us decide.

03
THE BIG IDEA

The Secret World Under the Ocean

Our theme grew from marine-life facts into an ocean adventure with ecosystems, depth zones and conservation.

What I learned: A small idea can grow when I ask more creative questions.

04
MORE CURIOSITY

What about geography?

We asked for more latitude, longitude, ocean trenches, underwater mountains and comparisons with land. That inspired the Ocean GPS and Land vs Sea activities.

What I learned: Interactive comparisons can make science easier to understand.

05
BUILD & EXPERIMENT

Turning ideas into a real website

ChatGPT helped create Hugo templates, CSS styles, JavaScript interactions and a version that could be copied to a USB drive.

What I learned: HTML gives structure, CSS adds style and JavaScript creates interactions.

06
DEBUGGING

Errors are clues!

GitHub Pages setup produced a “Get Pages site failed” error. Later, Hugo warned that .Site.Data was deprecated. We used the error messages to find fixes, including hugo.Data.

What I learned: Understanding an error is part of solving it.

07
SHARE & IMPROVE

OceanQuest goes live!

We published the project with GitHub Actions and GitHub Pages, while keeping an offline USB version. Then we continued adding new geography activities.

What I learned: Building a website is a process of testing, learning and improving.

REAL QUESTIONS FROM OUR CONVERSATION

Prompts that changed the project.

These are real requests from the development conversation. Some were entered with adult help; this is a family-supported school project.

CHOOSING TOOLS
“Help me understand how Hugo can build an image-rich website that also works offline.”

What changed: I learned what a static site generator does and why Hugo fits this project.

DESIGNING FOR IMAGES
“I want to build a website which predominantly include embeded images”

What changed: We chose Hugo for its built-in image processing.

THE THEME
“The secret world under the ocean”

What changed: The project became an underwater discovery adventure.

GEOGRAPHY FIRST
“also emphasize more on geographical facts ... compare and contrast with land, latitude logituted etc”

What changed: We added ocean geography, coordinates and land comparisons.

MAKE IT REAL
“lets implement give me downloadable zip file and instructions to run on development computer”

What changed: We created the first Hugo project and USB instructions.

LEARN FROM ERRORS
“Get Pages site failed”

What changed: We fixed GitHub Pages configuration and got the site published.

MY BIGGEST DISCOVERY

AI is a helper. Curiosity is the compass.

ChatGPT can suggest ideas, explain code and help with debugging. But I still need to ask good questions, check facts, test what works and keep improving.
